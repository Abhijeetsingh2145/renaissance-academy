# Memory --- Renaissance Academy Website

## Project

Renaissance Academy website redesign.

## Location

Gorakhpur, Uttar Pradesh --- Bala Par/Baijnathpur area.

## Existing Website

https://renaissanceacademy.org.in/index.php

## Supplied Reference Website

https://bnpublicschool.in/

Use the reference website only for ideas and information breadth. Do not
copy its homepage density or structure.

## Social Reference

Facebook: https://www.facebook.com/profile.php?id=100057387973333

## Brand

-   Existing logo is available.
-   Existing blue brand colour is the primary brand colour.
-   Desired positioning: premium modern school.

## Product Goals

-   Generate admissions.
-   Provide school information.
-   Improve online presence.

## Scope Decisions

-   English-only website.
-   Complete new website.
-   Homepage should remain focused and uncluttered.
-   Detailed information belongs on inner pages.
-   Content creation is shared 50/50 between school and project team.
-   Domain is owned by the school.
-   Domain transfer and hosting are managed by the project owner.
-   No ongoing maintenance requirement after launch.

## Admin Decisions

-   One admin account.
-   Admin can view admission submissions.
-   Admin can create, edit, delete, publish/hide and expire notices.
-   No CRM or role/permission system.

## Admission Fields

-   Parent/Guardian Name.
-   Student Name.
-   Date of Birth.
-   Class Seeking Admission.
-   Phone Number.
-   Email Address.
-   Previous School.

## Notifications

-   Store submissions.
-   Email notification.
-   WhatsApp notification.
-   Public floating WhatsApp contact button.

## Available Content/Assets

-   Logo.
-   Brand colour.
-   School photographs/videos.
-   Principal, Chairman and Director information, messages and
    photographs.
-   Academic information.
-   Facilities information.
-   Admission information.
-   Fee information.
-   Achievements.
-   Events/activities.
-   CBSE disclosure information/documents.
-   School rules/policies.

Teacher information is not confirmed and must not be invented.
