# Design --- Renaissance Academy Website

## 1. Design Direction

Create a premium, modern school website that feels:

-   Trustworthy.
-   Sophisticated.
-   Academic.
-   Welcoming.
-   Aspirational.

The design should appeal primarily to parents while remaining engaging
for students.

## 2. Brand

Use the existing Renaissance Academy logo.

Use the blue from the existing logo as the primary brand colour.

Build supporting colours and neutrals around the existing brand colour
rather than replacing the school's identity.

## 3. Visual Style

Use:

-   Strong typography.
-   High-quality authentic school photography.
-   Generous whitespace.
-   Clear hierarchy.
-   Editorial-style layouts.
-   Refined UI elements.
-   Subtle motion.

Avoid:

-   Generic school-template appearance.
-   Childish styling.
-   Excessive colours.
-   Excessive gradients.
-   Excessive cards.
-   Excessive shadows.
-   Excessive rounded containers.
-   Over-animation.
-   Visual clutter.

## 4. Homepage

The homepage must be selective and uncluttered.

It should tell a clear story rather than reproduce the entire website.

Preferred content flow:

1.  Hero.
2.  School introduction.
3.  What makes Renaissance Academy distinctive.
4.  Academics snapshot.
5.  Campus/student-life visual section.
6.  Achievements.
7.  Visual story/gallery.
8.  Admission CTA.
9.  Contact.

The exact order may be refined during implementation.

Detailed information belongs on inner pages.

## 5. Navigation

Navigation must be simple and intuitive.

Primary areas such as About, Academics, Facilities, Activities,
Admissions, Gallery and Contact must be easy to access.

Admission should have clear prominence.

## 6. Typography

Use modern, highly readable typography.

Create a clear hierarchy for:

-   Display headings.
-   Section headings.
-   Subheadings.
-   Body text.
-   Supporting text.
-   Buttons.

Do not select fonts that materially harm performance.

## 7. Layout

Use consistent:

-   Spacing.
-   Alignment.
-   Content widths.
-   Section rhythm.
-   Responsive behavior.

Use whitespace intentionally.

Avoid repetitive section patterns throughout the site.

## 8. Photography & Video

Prioritize authentic Renaissance Academy imagery.

Use photography to communicate:

-   Campus.
-   Students.
-   Classrooms.
-   Teachers where approved.
-   Facilities.
-   Sports.
-   Activities.
-   Events.
-   Achievements.
-   School community.

Do not use stock imagery as a representation of the school when
authentic imagery is available.

## 9. Motion

Use subtle, purposeful animation for:

-   Page/section reveals.
-   Image transitions.
-   Hover states.
-   Navigation interactions.

Do not use animation that distracts from content or harms performance.

Respect reduced-motion preferences.

## 10. Admission CTA

Admission actions should be clearly visible throughout the website.

The path from discovering the school to submitting an enquiry should
feel simple and trustworthy.

## 11. Notice Board

Provide a right-side notice-board control/popup.

The public component should display active published notices without
overwhelming the main page.

## 12. WhatsApp

Provide a persistent WhatsApp button at the bottom-right.

It must remain easy to access without obstructing important content or
controls.

## 13. Responsive Design

Design mobile as a primary experience.

The website must adapt cleanly to:

-   Mobile.
-   Tablet.
-   Desktop.
-   Large screens.

## 14. Accessibility

Maintain:

-   Readable typography.
-   Adequate contrast.
-   Visible focus states.
-   Accessible controls.
-   Keyboard usability.
-   Appropriate alt text.
-   Reduced-motion support.

## 15. Design Principle

The website should feel like a premium modern educational institution,
not a generic school template.

The homepage should create interest and trust; the inner pages should
provide depth.
